ОБЪЯСНЕНИЕ ЗАДАЧ ИЗ ФАЙЛА 01 СТРУКТУРЫ УЧЕНИК И СТУДЕНТ

Введение
Структура Student содержит поля: name (char[51]), surname (char[51]), age (unsigned int), grade (unsigned int), mark_count (unsigned int), marks (int*). Для удобства все действия вынесены в методы структуры: read, print, avg_mark, will_graduate, age_enterance, add_mark.

1.1 Ученик 1
Задача: считать 5 учеников и вывести их.
Решение: в main создаётся массив из 5 Student. Для каждого вызывается read(), затем print(). Метод read считывает имя, фамилию, возраст, класс, количество оценок и сами оценки (динамический массив). Метод print выводит данные в том же формате.

1.2 Ученик 2
Задача: вычислить средний балл каждого из 5 учеников.
Решение: после считывания 5 учеников, для каждого вызывается avg_mark(), которая суммирует оценки и делит на их количество. Вывод с точностью 6 знаков.

1.3 Ученик 3
Задача: определить, сколько учеников выпустится через N лет. Ученик выпускается после 11 класса.
Решение: считывается N. Затем 5 учеников. Для каждого вызывается will_graduate(N), которая возвращает true, если grade + N > 11. Подсчитывается количество true и выводится.

2.1 Ученик 4
Задача: для каждого ученика вывести возраст, в котором он пошёл в первый класс.
Решение: метод age_enterance вычисляет age - grade + 1. Например, если ученику 15 лет и он в 7 классе, то в первый класс он пошёл в 15 - 7 + 1 = 9 лет. Выводится для каждого из 5 учеников.

2.2 Ученик 5
Задача: преподаватель добавляет пятёрки, пока средний балл не станет >= 4.5. Вывести обновлённый журнал.
Решение: считываются 5 учеников. Для каждого в цикле while (avg_mark() < 4.5) вызывается add_mark(5). Метод add_mark создаёт новый массив оценок на 1 больше, копирует старые, добавляет новую оценку, удаляет старый массив. После этого выводится журнал.

3.1 Журнал
Задача: создать структуру Journal с динамическим массивом учеников и его размером. Написать функции read и print.
Решение: структура Journal содержит count и Student* data. Метод read считывает count, выделяет память под массив, затем для каждого ученика вызывает read(). Метод print выводит count и всех учеников.

3.2 Журнал 2
Задача: добавить каждому ученику итоговую оценку на основе среднего балла.
Решение: метод add_total_marks для каждого ученика вычисляет avg_mark(). Если avg >= 4.5, оценка 5; иначе если >= 3.5, то 4; иначе если >= 2.5, то 3; иначе 2. Затем вызывается add_mark с этой оценкой. После этого журнал выводится.

3.3 Журнал 3
Задача: удалить из журнала учеников со средним баллом меньше X (по умолчанию 4.5).
Решение: метод filter_avg_above принимает X. Для каждого ученика, если avg_mark() >= X, выводит его. В main считывается журнал, затем X, вызывается filter_avg_above(X). Выводятся только подходящие ученики.

3.4 Журнал 4
Задача: удалить дубликаты учеников из журнала. Дубликатом считается ученик с полностью совпадающими полями.
Решение: метод equal_students сравнивает двух учеников по всем полям: имя, фамилия, возраст, класс, количество оценок и все оценки. Если все совпадает, возвращает true. Метод remove_duplicates проходит по журналу, для каждого ученика сравнивает с последующими. Если найден дубликат, удаляет его сдвигом всех последующих элементов влево и уменьшает count. В main считывается журнал, вызывается remove_duplicates, выводится результат.
