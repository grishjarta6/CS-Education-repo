ОБЪЯСНЕНИЕ ЗАДАЧ ИЗ ФАЙЛА 02 ВВЕДЕНИЕ В КЛАССЫ

1.1 Классный котик – 1
Задача: описать класс Cat с одним полем int age.
Решение: класс Cat1 содержит только public: int age. В main создаётся объект my_cat, считывается age, выводится строка "Age of my cat is " и возраст.

1.2 Классные часы – 1
Задача: дописать код в main для класса Clock с полями hours и minutes.
Решение: класс Clock1 содержит public: int hours, int minutes. В main создаётся объект my_clock, считываются часы и минуты, выводится строка "hours: h minutes: m".

1.3 Классные часы – 2
Задача: реализовать класс Clock с тремя полями hours, minutes, seconds и написать main для тестирования.
Решение: класс Clock2 содержит public: int hours, minutes, seconds. В main создаётся объект my_clock, считываются три значения, выводится строка "hours: h minutes: m seconds: s".

1.4 Классный котик – 2
Задача: для класса Cat с полями age и buildYear написать код, который для каждого котика (их количество неизвестно) вычисляет год подзарядки как buildYear + age и выводит "С.А.Т. number need recharging at year".
Решение: класс Cat2 содержит public: int age, buildYear. В main используется бесконечный цикл while(1). Считываются age и buildYear. Если ввод неудачен, цикл прерывается. Выводится строка с номером number (начинается с 1) и годом buildYear + age. number увеличивается.

1.5 Классный котик – 3
Задача: добавить в класс Cat поле string name. Написать программу для тестирования нескольких котиков с проверкой вводимых данных: age от 1 до 100, buildYear от 2018 до 2034. Выводить "C.A.T. name build in buildYear and can work X years".
Решение: класс Cat3 содержит public: string name; int age; int buildYear; и метод fix(), который корректирует age и buildYear в допустимые пределы. В main бесконечный цикл, считываются name, age, buildYear. Если ввод неудачен, выход. Вызывается fix(). Выводится строка с именем, годом постройки и количеством лет работы.

2.1 Классные часы – 3
Задача: написать функцию changeTime(Clock &clock, int seconds), которая переводит время на указанное количество секунд (можно назад и вперёд).
Решение: класс Clock содержит public: int hours, minutes, seconds. Функция changeTime переводит всё время в секунды, прибавляет seconds. Если сумма отрицательная, добавляет 86400 (количество секунд в сутках) и берёт остаток по модулю 86400. Затем сумма приводится к диапазону [0, 86400). Далее вычисляются новые часы, минуты, секунды. В main считываются три числа, затем seconds, вызывается changeTime, выводится время в формате h:m:s.

2.2 Классный котик – 4
Задача: исправить код марсианских программистов. Ограничения: age от 1 до 100, buildYear от 2018 до 2034. Выводить "C.A.T. name need recharging at year".
Решение: класс Cat4 содержит private: int age, buildYear; string name; public: метод set, который устанавливает значения с проверкой, и метод print, который выводит строку с именем и годом подзарядки (buildYear + age). В main создаются три объекта, для каждого считываются имя, возраст, год постройки, вызывается set, затем print. Выводятся три строки.
